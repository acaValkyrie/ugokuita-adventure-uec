# 音声のクレジット

- `running_loop.wav`: 機体の実機の走行音の録音（リポジトリ acaValkyrie/ugokuita-adventure の `audio/動く板　ガッタン.m4a` の 9〜11 秒）から `tools/make_running_loop.py` で作成。製作者本人の録音。
- `bump/bump_a.ogg`, `bump/bump_b.ogg`: 機体の実機の録音（同リポジトリの `audio/動く板　ガッタン３.m4a` の 2.06 秒と 2.68 秒の衝撃音）から `tools/make_bump_sounds.py` で切り出し。製作者本人の録音。
- `grass/rustle*.ogg`: qubodup「20 Rustles of dry leaves」 https://opengameart.org/content/20-rustles-dry-leaves — CC0 1.0 (http://creativecommons.org/publicdomain/zero/1.0/)。`tools/convert_rustles.py` で8種類を選び、モノラル・音量をそろえてOGGに変換。
- `water/running_stream.ogg`: AllyInNature「Running stream/ water sound」 https://pixabay.com/sound-effects/nature-running-stream-water-sound-239612/ — Pixabay Content License（https://pixabay.com/service/license-summary/ ）。クレジット表記は不要。水の上を走っている間に流す。元の mp3（555秒）の 30〜52 秒から `tools/make_water_sounds.py` で20秒のループを作って Ogg に変換した。規約で素材を単体で配布することが禁止されているので、リポジトリには暗号化した `water/running_stream.ogg.enc` だけを置き、GitHub Actions でシークレット `BGM_KEY` を使って復号する。元の mp3 は `bgm/source/` に置いている。
- `water/water_splash.ogg`: Universfield「Water Splash」 https://pixabay.com/sound-effects/film-special-effects-water-splash-199583/ — Pixabay Content License。クレジット表記は不要。機体がプールの水面をまたいだときに鳴らす。`tools/make_water_sounds.py` でモノラルにし、末尾の無音を削って Ogg に変換した。`running_stream.ogg` と同じ理由で、暗号化した `water/water_splash.ogg.enc` だけを置いている。
- `drift/drift_charge.ogg`, `drift/drift_charge_loop2.ogg`, `drift/drift_charge_loop3.ogg`, `drift/drift_dash.ogg`: LegoLunatic（Freesound。Pixabay では freesound_community が投稿）「Charged laser」 https://pixabay.com/sound-effects/film-special-effects-charged-laser-7125/ — Pixabay Content License。クレジット表記は不要。ドリフト中にチャージ音を流し、ドリフトのダッシュで発射音を鳴らす。元の mp3 の 0〜2.4 秒（出だし）、2.4〜2.9 秒と 2.9〜3.4 秒（それぞれ継ぎ目なくループするように加工）、4.45〜7.9 秒（発射音）から `tools/make_drift_sounds.py` で作成した。規約で素材を単体で配布することが禁止されているので、リポジトリには暗号化した `drift/*.ogg.enc` だけを置き、GitHub Actions でシークレット `BGM_KEY` を使って復号する。元の mp3 は `bgm/source/` に置いている。
- `water/splash_*.ogg`: rubberduck「40 CC0 water / splash / slime SFX」 https://opengameart.org/content/40-cc0-water-splash-slime-sfx — CC0 1.0 (http://creativecommons.org/publicdomain/zero/1.0/)。
- `fanfare/fanfare_02.ogg`: Fantasy Musica（Beau Buckley）「Fanfare 02」 https://opengameart.org/content/fanfare-02 — CC-BY-SA 4.0 (http://creativecommons.org/licenses/by-sa/4.0/)。クレジット: Beau Buckley。パワーアップアイテムを取ったときに鳴らす。元の OGG をそのまま使用（改変なし）。
- `bgm/ending2_fanfare_1.mp3`: tcarisland「Fanfare 1」 https://opengameart.org/content/fanfare-1 — CC-BY 4.0 (https://creativecommons.org/licenses/by/4.0/)。クレジット: tcarisland。エンディング2（空を飛べるパワーアップで一定の高さを越えて無重力になったとき）の BGM。元の MP3（ページ上の `Fanfare_2.mp3`）をそのまま使用（改変なし）。
- `bump/rattle_a.wav`〜`bump/rattle_d.wav`: 段差の音に重ねるプラスチック部品のカチャカチャ音。`tools/gen_rattle.gd` でノイズから合成した自作の音。
- `bgm/これにてお開き、また来週！.mp3`: 秦暁「これにてお開き、また来週！」 https://opentracks.com/bgm/detail/23343 — フリーBGM オープントラックス（旧DOVA-SYNDROME）。クレジット表記は不要（作曲者の条件でも任意）。規約で音源の公開が禁止されているため、リポジトリには暗号化した `bgm/ending_bgm.mp3.enc` だけを置き、GitHub Actions でシークレット `BGM_KEY` を使って復号する。
- `bgm/city_bird.ogg`: 「VSQSE_0586_city_bird」 https://vsq.co.jp/plus/sound/category_sub/city/page/2/ — VSQ plus+ の効果音（規約 https://vsq.co.jp/plus/tos/ ）。クレジット表記は不要。規約で「オリジナルの状態での各種効果音および楽曲の頒布」（インターネットでの再配信を含む）が禁止されているため、元の mp3（320kbps）を Ogg 96kbps に変換したうえで、リポジトリには暗号化した `bgm/city_bird.ogg.enc` だけを置き、GitHub Actions でシークレット `BGM_KEY` を使って復号する。元の mp3 は `bgm/source/`（Godot も git も無視する）に置いている。
